# JavaScript Learning

<img src="https://cdn.simpleicons.org/javascript/F7DF1E" width="80" alt="JavaScript Logo">

A repository for learning and practicing JavaScript, organized into three difficulty levels:

* **Easy** — JavaScript basics, `getElementById()`, `innerText`, `addEventListener()`, and basic DOM manipulation.
* **Medium** — More advanced DOM manipulation, events, functions, arrays, objects, and user input.
* **Hard** — Complex logic, advanced DOM manipulation, and challenging JavaScript exercises.

This repository documents my progress from JavaScript fundamentals to more advanced concepts.
